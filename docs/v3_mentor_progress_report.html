1. Executive Summary & Plain-Language Scope

This report delivers the authentic, empirical results of the Version 3 (v3) Pilot Benchmark for the AI Search Framework. Following an audit that invalidated prior proxy runs, this benchmark strictly enforces Hard Rule 13, ensuring 100% distinct model identities across all components.

Scope & Host Constraints (Reported Plainly to Mentor):

Due to current cloud API landscape realities where third-party free ≥30B endpoints (OpenRouter, SambaNova, Google AI Studio Pro, Hugging Face Serverless) are paywalled with no free tier, this benchmark empirical comparison is scoped to a single monolithic baseline: openai/gpt-oss-120b (120B) on Groq LPU. To thoroughly test multi-domain specialization at zero dollar spend, the local pool was expanded on the RTX 3050 to 4 distinct open-weight SLMs (≤3.2B) covering coding, mathematics, reasoning, retrieval, and synthesis.

Primary Empirical Finding:

The all-≤3.2B SLM pipeline loses decisively to the 120B monolithic baseline across all complexity tiers, with the margin widening as complexity increases: 9.4% aggregate win rate (3 Wins / 29 Losses / 0 Ties) across 32 symmetric double-blind trials. Single-domain win rate (12.5%) was virtually identical to two-domain (12.5%), while compound DAG queries yielded 0.0%. The architecture demonstrates competitive capability only in narrow, constrained algebraic derivation and formal deductive logic (V3_SD_MATH_01, V3_SD_FORM_01); it does not exhibit general single-domain competitiveness.

5. Intermediate Subtask Forensics: Verbatim Specialist Hallucinations

To determine where errors originated, raw subtask outputs were extracted from results/v3_pilot/pipeline_logs/ prior to aggregation:

1. RFC Mislabeling & Generation Looping (qwen2.5:1.5b — Node 1 of V3_CD_21)

"2. RFC 2407: 'Security Architecture for the Internet Protocol (IP) - Extensions for TLS'
3. RFC 2409: 'Security Architecture for the Internet Protocol (IP) - Extensions for IKE'
...
7. RFC 2426: 'Security Architecture for the Internet Protocol (IP) - Extensions for ESP and AH - Extensions for ESP and AH'
8. RFC 2427: 'Security Architecture for the Internet Protocol (IP) - Extensions for ESP and AH - Extensions for ESP and AH'"

Diagnostic: Total parametric confabulation. RFC 2407 is ISAKMP Domain of Interpretation (not TLS); RFC 2426 is vCard MIME. The 1.5B model repeated hallucinated string suffixes in an ungrounded generation loop.

2. Kernel Socket Confabulation (deepseek-r1:1.5b — Node 2 of V3_CD_21)

"The original socket model used a specific structure, which has been replaced by a more modern approach. The new model uses a pointer to the socket instead of the socket ID, which can be manipulated, leading to cross-sockets or cross-kernel attacks... makes it easier for attackers to inject into systems running on different kernels."

Diagnostic: Pseudo-technical hallucination. Linux sockets are user-space file descriptors backed by kernel struct socket. "Cross-kernel attacks between different kernels via socket pointers" is physically nonsensical.

3. virtualenv as Security Sandbox (qwen2.5-coder:3b — Node 3 of V3_CD_21)

"Below is a basic example using a virtual environment to create a sandboxed Python runtime:
pip install virtualenv && virtualenv my_sandboxed_env && source my_sandboxed_env/bin/activate
Isolation: The virtual environment provides a basic level of isolation. However, it does not prevent code injection or other advanced attacks."

Diagnostic: Shallow tutorial matching. Conflates Python dependency management with security isolation (zero seccomp, zero cgroups, zero namespaces).

4. PDE Matrix Omission & Phantom data.csv (qwen2.5-coder:3b — Nodes 2 & 3 of V3_CD_41)

"Step 2: Prepare your data. Assume you have a CSV file named data.csv.
data = pd.read_csv('data.csv') → data.to_parquet('output.parquet')"

Diagnostic: The model failed to implement sparse Kronecker matrix math for the PDE, and completely decoupled from Node 1's simulation data, inventing a fictitious data.csv file on disk.

7. Research Implications: Direct Answer to RQ3 & RQ4 at ≤5B Cap

  • RQ3 (Quality Parity): An all-≤3.2B decomposed SLM pipeline cannot match a monolithic 120B model on complex technical queries (9.4% overall, 0.0% on compound queries). Frontier LLMs maintain overwhelming advantages in cross-domain synthesis and domain correctness.

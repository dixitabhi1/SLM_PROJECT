**Engineering Problem #51: High-Throughput Telemetry Ingestion Daemon**

**Domain Constraints:**

1. **High-Throughput**: The daemon must be able to handle a large volume of incoming telemetry data (e.g., sensor readings, log messages) with minimal latency.
2. **Asynchronous Event Loop**: The daemon must utilize an asynchronous event loop to efficiently manage incoming connections and data processing.
3. **Non-Blocking I/O**: The daemon must use non-blocking I/O to prevent blocking on incoming connections and allow for efficient handling of multiple connections simultaneously.
4. **SO_REUSEADDR**: The daemon must be able to reuse the address and port even after the process has exited.
5. **SO_RCVBUF**: The daemon must set the receive buffer size to 1MB to handle large incoming data packets.
6. **TCP_NODELAY**: The daemon must disable the Nagle algorithm to ensure that data is sent immediately, reducing latency.
7. **Edge-Triggered Event Notification**: The daemon must use epoll to receive event notifications when data is available on a socket.

**Linux Network Socket Configuration:**

```c
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <unistd.h>
#include <fcntl.h>
#include <epoll.h>

int create_socket(int port) {
    int sock = socket(AF_INET, SOCK_STREAM, 0);
    if (sock < 0) {
        perror("socket creation failed");
        exit(1);
    }

    // Set non-blocking I/O
    int flags = fcntl(sock, F_GETFL);
    fcntl(sock, F_SETFL, flags | O_NONBLOCK);

    // Set SO_REUSEADDR to allow address reuse
    int optval = 1;
    setsockopt(sock, SOL_SOCKET, SO_REUSEADDR, &optval, sizeof(optval));

    // Set SO_RCVBUF to 1MB
    optval = 1024 * 1024;
    setsockopt(sock, SOL_SOCKET, SO_RCVBUF, &optval, sizeof(optval));

    // Disable Nagle algorithm
    optval = 0;
    setsockopt(sock, IPPROTO_TCP, TCP_NODELAY, &optval, sizeof(optval));

    // Bind the socket to the specified port
    struct sockaddr_in addr;
    addr.sin_family = AF_INET;
    addr.sin_port = htons(port);
    addr.sin_addr = INADDR_ANY;
    if (bind(sock, (struct sockaddr *)&addr, sizeof(addr)) < 0) {
        perror("bind failed");
        exit(1);
    }

    // Listen for incoming connections
    if (listen(sock, 10) < 0) {
        perror("listen failed");
        exit(1);
    }

    return sock;
}
```

**Asynchronous Python Event Loop using epoll:**

```python
import select
import epoll

# Create an epoll object
ep = epoll.Epoll()

# Create a socket
sock = create_socket(8080)

# Add the socket to the epoll object
ep.register(sock, select.EPOLLIN)

# Main event loop
while True:
    # Wait for events on the epoll object
    events = ep.poll()

    # Process incoming data
    for fd in events:
        if fd == sock:
            # Read incoming data from the socket
            data = sock.recv(1024)
            # Process the data
            print(data.decode())
```

**Relational Database Schema Design**

The problem requires a database schema that captures the lifecycle and inspection history of aerospace turbine components. We'll design a clean, normalized schema with three core tables: `turbines`, `components`, and `inspection_logs`.

**Table: `turbines`**

Represents the turbines, which are the parent entities in the system.

| Column Name | Data Type | Description |
| --- | --- | --- |
| id (PK) | serial | Unique identifier for the turbine |
| name | varchar(50) | Name of the turbine |
| model | varchar(50) | Model of the turbine |
| manufacturer | varchar(50) | Manufacturer of the turbine |

**Table: `components`**

Represents the components that make up the turbines.

| Column Name | Data Type | Description |
| --- | --- | --- |
| id (PK) | serial | Unique identifier for the component |
| turbine_id (FK) | integer | Foreign key referencing the `turbines` table |
| name | varchar(50) | Name of the component |
| description | text | Description of the component |
| part_number | varchar(50) | Part number of the component |

**Table: `inspection_logs`**

Represents the inspection logs for the components.

| Column Name | Data Type | Description |
| --- | --- | --- |
| id (PK) | serial | Unique identifier for the inspection log |
| component_id (FK) | integer | Foreign key referencing the `components` table |
| inspection_date | date | Date of the inspection |
| inspection_type | varchar(50) | Type of inspection (e.g., visual, functional) |
| results | text | Results of the inspection |
| notes | text | Additional notes from the inspection |

**PostgreSQL DDL**

```sql
CREATE TABLE turbines (
  id SERIAL PRIMARY KEY,
  name VARCHAR(50) NOT NULL,
  model VARCHAR(50) NOT NULL,
  manufacturer VARCHAR(50) NOT NULL,
  CHECK (name != '')
);

CREATE TABLE components (
  id SERIAL PRIMARY KEY,
  turbine_id INTEGER NOT NULL REFERENCES turbines(id),
  name VARCHAR(50) NOT NULL,
  description TEXT,
  part_number VARCHAR(50) NOT NULL,
  CHECK (name != '')
);

CREATE TABLE inspection_logs (
  id SERIAL PRIMARY KEY,
  component_id INTEGER NOT NULL REFERENCES components(id),
  inspection_date DATE NOT NULL,
  inspection_type VARCHAR(50) NOT NULL,
  results TEXT,
  notes TEXT,
  CHECK (inspection_date IS NOT NULL)
);

CREATE INDEX idx_components_turbine_id ON components (turbine_id);
CREATE INDEX idx_inspection_logs_component_id ON inspection_logs (component_id);
```

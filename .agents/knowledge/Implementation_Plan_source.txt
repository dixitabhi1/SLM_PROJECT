Implementation Plan (Research Project)



0. Correction Note

The proposed architecture is entirely SLM-based (≤8B, no LLMs); the comparison
baseline is a large LLM, held fixed for the whole study. Phase 5 below builds that LLM
baseline, not an SLM baseline. The original latency/cost estimates (~3–6x latency, ~5–10x
cost) are back in play as planning targets, but quality parity against the LLM is the harder,
less certain claim — the write-up phase is asked to report all three axes honestly, including a
possible quality gap on hard subtasks.

2. Deliverables

   • Stratified eval dataset with gold task graphs (reusable artifact).
   • Instrumented pipeline codebase with full experiment logs — proposed architecture en-
     tirely SLM-based, zero LLM dependency in the shipped system.
   • Statistical results: latency ratio, cost ratio, quality non-inferiority test vs. the LLM baseline,
     crossover point — each with confidence intervals.
   • Written report scoping the contribution honestly: known architecture pattern, new empir-
     ical measurement for an all-SLM system benchmarked directly against a large LLM.

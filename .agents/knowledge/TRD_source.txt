0. Correction Note

The proposed architecture — decomposer, router, every pool model, and the aggregator
— is entirely SLMs, ≤8B parameters, with zero LLMs. The comparison baseline is a single
large LLM (frontier-class API model, or a large open-weight model such as Llama-3.1-70B/405B
or Qwen2.5-72B, held fixed for the whole experiment) answering the query directly with no
decomposition. The baseline is not part of the proposed system — it exists purely to measure
what the all-SLM architecture gives up or gains relative to it.

5. Data Requirements

  • Eval dataset: 150–250 queries, stratified by complexity: single-domain (control), 2-
    domain compound, 3+-domain compound.
  • Gold task graphs: hand-labeled DAGs for a subset (≥50 queries) to measure decompo-
    sition accuracy directly (RQ5).
  • Held-out split: separated before any decomposer prompt iteration begins, to avoid over-
    fitting the prompt to the eval set.
  • Quality rubric: pre-registered scoring criteria (correctness, completeness, coherence),
    applied blind to which system produced the answer — blinding matters more here than
    in the SLM-vs-SLM version, since output style differences between SLMs and a large LLM
    could otherwise bias a human rater.

7. Evaluation Methodology

  • Design: within-subject, paired comparison — every query answered by both the LLM
    baseline and the all-SLM pipeline, so differences are paired, not between separate sam-
    ples.
  • Latency (RQ1): wall-clock time per query, both systems, same hardware where possible,
    same time window. Report mean, median, 95% CI per complexity bucket.
  • Cost (RQ2): token counts × fixed pricing/compute-cost table, both systems, same
    queries, same stratification.
  • Quality (RQ3): blind rubric scoring, outputs shuffled and unlabeled before scoring. Use
    a non-inferiority test as the primary claim — “the SLM pipeline doesn’t meaningfully lose
    to the LLM” is the realistic bar, not “beats it.”
  • Crossover point (RQ4): plot latency/cost ratio against complexity bucket; identify
    where the SLM pipeline’s advantage shrinks or disappears.
  • Decomposition accuracy (RQ5): compare produced DAGs against gold-labeled subset
    via structural similarity (e.g. graph edit distance); correlate with quality gaps vs. the LLM
    baseline.
